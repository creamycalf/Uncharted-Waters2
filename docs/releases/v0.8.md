# 大航海时代2 v0.8

Android 8.0+ 横屏预发布测试版，包名 `org.local.uw2mobile`，versionCode 10。沿用之前的本地测试证书，覆盖安装即可保留本应用存档，不要先卸载。

本次汇总 0.7–0.8 的改动：全屏游戏与按场景显示的悬浮按键；首页和加载图铺满并遮住 DOSBox；修改器入口与菜单平级；武器、防具修改；25 种船型图片、基础性能及用途参考；全海图、130 个港口与普通村落解锁；离线图文入门攻略。保留滑动、摇杆、实验性城市点按寻路、1×–3× 速度、音乐及既有船只/海员修改。

点“工具”展开菜单、修改器和设置。修改进度须先保存，选择记录，备份并应用，再读取该记录。水粮补丁下次启动生效。地图修改保留藏宝记录与奖励流程；切换船型不解锁造船厂售卖条件。

20 项 Node 测试及 APK 的 246 项资源校验通过，v2/v3 签名通过。浏览器真实 DOS 引擎验证过城市全屏、直接触摸菜单、按钮切换、修改后原生读档/重新保存以及加载遮罩。尚未完成 Android 真机、所有对话/海战及全剧情验收，水粮补丁连续航行对照仍待完成。详细结果见验证记录及技术交接。
