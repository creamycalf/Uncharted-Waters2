# 大航海时代2 v0.6.1

Android 8.0+，横屏，**预发布测试版**。

## 下载与安装

下载附件 **Uncharted-Waters-2-Mobile-0.6.1.apk** 安装。已经使用本项目之前的适配版，可以直接覆盖安装，**不要先卸载**，以保留应用内存档。

应用名称：**大航海时代2**。包名：`org.local.uw2mobile`。版本号：`0.6.1-mobile`，versionCode `7`。与本项目 0.6 及更早适配版使用相同测试签名；与原作者应用是不同包名，不会自动迁移其私有存档。

## 本次提供的功能

- 直接触摸选人、对话与菜单；保留独立左键、右键及滑鼠模式。
- 人物/船只支持滑动与摇杆；城市可见道路支持实验性点按寻路。
- 1×–3× 可调速度、铺满/等比画面、音乐开关。
- 金钱与三类声望修改。
- 船只类型、耐久、推进、转向、水手人数与舱位、火炮与炮舱、货舱修改。
- 主角与已加入海员的能力、等级、忠诚度和技能修改。
- 修改前完整存档备份及恢复；可选下次启动生效的不耗粮食、不耗水补丁。
- 帆船图标；本次小版本将应用名称统一为“大航海时代2”。

修改器入口：**菜单 → 修改器**。先保存游戏，选择记录修改，点击“备份并应用”，再读取同一个记录生效。海员暂按职务、等级和存档编号区分，原游戏中文姓名保留。

## 验证与限制

17 项 Node 测试通过。真实 DOS 引擎的浏览器测试验证了修改后的船只/海员信息、原生重新存档保留修改，以及完整备份恢复；APK 的 219 个资源和 v2/v3 签名校验通过。

当前使用本地测试证书，尚未完成 Android 真机性能和全剧情验收。点按寻路主要在塞维尔港验证；海上自动航线、跨地图寻路未实现。水粮补丁的连续航海对照验收仍待完成。完整范围见仓库 README 和附件验证记录。
