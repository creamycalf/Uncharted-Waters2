# 大航海时代2 v0.8.2

Android 8.0+ 横屏预发布测试版，版本号 0.8.2-mobile / versionCode 12，包名 org.local.uw2mobile。沿用现有测试签名，可覆盖本项目旧版，保留应用内存档；不要先卸载。

本版重点补齐人物攻略并调整入口：

- 展开“工具”后，“菜单”“修改器”“攻略”并排，直接点“攻略”打开。
- 六位主角独立攻略，共 57 个从开局到结局的关键步骤，包含条件、地点、时间和卡关排查。
- 原版头像、主线行程示意、当前人物搜索、手动阅读进度勾选，离线可用；原通用图文说明保留。
- 攻略来源和版本差异在 mobile/docs/guide-sources.md；勾选不会读写游戏任务状态。

保留 0.8 的全屏触控、按场景出现的悬浮控件、速度和音乐、船只/海员/装备/地图修改及可选水粮补丁。

20 项 Node 测试通过；攻略的六页内容、图片、搜索、勾选持久化、三种窗口尺寸和游戏内入口/返回经过浏览器真实 DOS 引擎检查；APK 254 项资源及 v2/v3 签名校验通过。攻略依据 DOS 剧本解码研究整理，尚未在本 APK 逐一完成六人物通关；Android 真机、全剧情和连续海上水粮对照仍未验收。

附件：APK、精确提交源码 ZIP、验证记录、SHA-256 校验表、原样保留的上游 v7.8 GPL 组件源码归档。源码包不含签名私钥和实际游戏测试存档。
